Tableau Visualization Extension

Bring your Tableau data into 3D.

3D Chart Viz is a Tableau visualization extension for creating interactive 3D charts with multiple shapes, animation, history, motion trails, labels, and customizable visual settings.

Features

Explore Tableau data using interactive 3D visualization and animation controls.

Interactive 3D

Display Tableau data using customizable 3D shapes and perspective.

Page Animation

Animate changes over time using a Tableau Page field with playback controls.

History & Trails

Keep previous states visible and connect them using motion trails.

Custom Appearance

Configure colors, labels, grid lines, opacity, trail styles, and more.

X / Y / Z Fields

Assign Tableau fields to multiple visual dimensions including an optional depth axis.

Experimental Visualization

Explore presentation-oriented and creative visualization techniques directly inside Tableau.

How to Use

  1. Add 3D Chart Viz to a Tableau worksheet.
  2. Assign Tableau fields to the available roles: X, Y, optional Z, Page, Detail, and Tooltip.
  3. Open the extension settings.
  4. Select a 3D shape and customize appearance settings.
  5. If a Page field is assigned, use the playback controls to animate changes over time.

About 3D Visualization

3D charts can be visually engaging, but perspective may make precise value comparison more difficult than conventional 2D charts. For analytical use cases where accurate comparison is the primary goal, consider using standard 2D visualizations alongside this extension.
